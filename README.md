# Stack Atlas Public Viewer

Public, linkable Stack Atlas build for the AIgora Republic homepage.

## Entry

- [Open Stack Atlas](index.html)

## What Is Included

- World map with country, chokepoint, company, technical-stack, and political-stack interaction.
- Chinese / English language switch. The page shows one language at a time.
- Technology Stack Map and Political Stack Map.
- Guided Paths, Cross-stack Overlap, Scenario Flow, Dual-stack Transmission, Political MAG, East Asia Energy, and Magnitude Layer views.
- Local static data only. No backend, no account login, no API key, and no live network fetch.

## Public Boundary

This directory is the public release surface. It intentionally excludes:

- Republic portrait assets.
- Agent diary, relationship notes, emotional logs, user profile notes, and service negotiations.
- Internal roadmap files and workbench notes that are not yet publication-ready.
- Imported case-library pages that have not been separately cleaned for public release.

## Evidence Boundary

Stack Atlas is an exploratory dependency viewer, not an oracle. Evidence status is shown in the UI. `needs-review`, `unknown`, `blocked`, and `source-linked` items must not be treated as verified conclusions.
